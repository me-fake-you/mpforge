# WeChat layout

Use the project renderer through mpforge render <article> or mpforge preview <article>. Select one of the registered themes with frontmatter, then inspect generated content/<slug>/build output at mobile width and in both light and dark modes.

Do not hand-build untested HTML or copy CSS from an unknown project. Resolve layout problems in Markdown, theme configuration, or the renderer contract; run mpforge lint <article> after changes. Layout work cannot approve or publish an article.
