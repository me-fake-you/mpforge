## 项目

MPForge — Git 驱动、Agent 友好的微信公众号 Content-as-Code 工作台。

## 推荐语

MPForge 把 Markdown、本地素材、确定性 Linter、浅色/深色预览、人工批准、Mock/Real 草稿边界和脱敏回执放进同一个 Git 工作流。

公开 Demo 只使用本地 Mock WeChat，不读取真实账号。Real Draft 需要用户自己的合法账号配置和本次人工确认；真实账号目前尚未测试。v0.1 不提供自动正式发布或群发，最后一步仍由用户在微信公众平台后台完成。

MPForge is **Based on WeMD by the WeMD Team**，保留 WeMD MIT 许可证、版权和固定上游 Commit，明确说明继承模块与新增模块。它不隶属于腾讯或微信。
