## 中文简介

MPForge 是一个本地优先的微信公众号 Content-as-Code 工作台：用 Git 追踪 Markdown、素材和状态，通过确定性 Linter 生成浅色/深色预览，在人工批准后进入本地 Mock 或受保护的 Real Draft 边界，并保存不含秘密的回执。

公开 Demo 只使用 Mock WeChat。Real Draft 需要用户自己的合法账号配置和对本次操作的人工确认；真实账号尚未测试，Mock 结果不代表真实公众号成功。v0.1 不支持自动正式发布或群发。

MPForge is **Based on WeMD by the WeMD Team**，保留上游 MIT 许可证、版权和固定 Commit；项目不隶属于腾讯或微信。公开仓库使用经过扫描的清洁源码历史，不包含有许可证冲突的上游 Server、本地缓存、工具链、私人内容或真实回执。
