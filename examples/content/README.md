# Public Content-as-Code examples

These three examples are fictional, original, and safe to publish. They contain no credentials, account identifiers, user images, or copied prose. Every image is a repository-local SVG created for MPForge under the repository MIT license.

- `technical-deterministic-build`: a technical article using the `tech-dark-accent` theme.
- `educational-review-loop`: an educational article using `academic-blue`.
- `complete-content-as-code`: a comprehensive article with code, a table, an image, and a quotation using `warm-editorial`.

Each example mirrors `content/<slug>/`. To exercise one in a disposable workspace, copy its directory into that workspace's `content/` directory; do not overwrite an existing article. Generated HTML, lint reports, screenshots, and receipts belong in `build/` and `receipts/` and are intentionally not presented here as already verified release evidence.

The examples deliberately leave `account` empty, so deterministic lint reports one expected warning while producing zero errors. Add a synthetic alias only in a disposable Mock Draft scenario; never add a real account identifier to a public example.
